# ValDoctor

Бесплатная программа для Windows 10 и 11. Проверяет, может ли компьютер подключиться к сервисам
Riot Games (Riot Client, VALORANT, League of Legends). Если причина в неверном сетевом адресе,
ValDoctor предлагает исправление через файл `hosts` и умеет полностью его отменить.

ValDoctor не связан с Riot Games и не одобрен ею. Версии 0.x предварительные: программа проверена
пока на небольшом числе компьютеров.

До версии 0.3.0 программа называлась RiotFix.

## Возможности

- Проверка шести сервисов, к которым подключается Riot Client: `auth.riotgames.com`,
  `account.riotgames.com`, `clientconfig.rpg.riotgames.com`, `entitlements.auth.riotgames.com`,
  `data.riotgames.com`, `sieve.services.riotcdn.net`. Для каждого проверяются DNS, TCP, TLS
  с сертификатом и ответ HTTPS.
- Поиск рабочего адреса через DNS-over-HTTPS (Cloudflare, Google Public DNS, Quad9, AdGuard).
  Адрес принимается, только если дважды подряд прошёл полную проверку.
- Исправление записью в `hosts` после вашего подтверждения и отмена одной кнопкой.
- Технический отчёт по кнопке ⓘ: его можно скопировать и приложить к сообщению о проблеме.
- Уведомление о новой версии на GitHub.

## Скачать и запустить

1. Скачайте `ValDoctor.exe` со страницы [Releases](https://github.com/IskhakovMA/riotfix/releases).
   Нужна 64-битная Windows 10 или 11, устанавливать .NET не нужно.
2. Запустите файл и нажмите «Проверить подключение».
3. Если ValDoctor нашёл исправление, нажмите «Исправить подключение» и подтвердите запрос
   администратора Windows.
4. Перезапустите Riot Client.

У `ValDoctor.exe` пока нет цифровой подписи, поэтому Windows SmartScreen может предупредить
о неизвестном издателе. Без подписи Windows не может проверить, кто выпустил файл. Скачивайте
ValDoctor только со страницы [Releases](https://github.com/IskhakovMA/riotfix/releases) этого
репозитория, копии с других сайтов не запускайте. Если файл скачан оттуда и вы решили его
запустить, в окне SmartScreen нажмите «Подробнее», затем «Выполнить в любом случае». Если
сомневаетесь, не запускайте.

Контрольная сумма из файла `ValDoctor.exe.sha256` показывает, что файл скачался целиком и не
повреждён:

```powershell
Get-FileHash .\ValDoctor.exe -Algorithm SHA256
```

От подмены эта проверка не защищает: тот, кто смог бы заменить EXE в релизе, заменил бы и файл
с контрольной суммой.

## Как работают исправление и откат

ValDoctor меняет только `C:\Windows\System32\drivers\etc\hosts` и только после подтверждения.
В конец файла добавляется отдельный блок:

```text
# >>> ValDoctor BEGIN (managed block, https://github.com/IskhakovMA/riotfix)
104.16.120.50 auth.riotgames.com # valdoctor:1a2b3c4d
# <<< ValDoctor END
```

Каждая строка блока помечена контрольной суммой. Строку, которую вы изменили вручную, ValDoctor
больше не считает своей и не трогает. Остальное содержимое файла сохраняется без изменений.
Если в `hosts` уже есть чужая запись для сервиса Riot, программа покажет её и закомментирует
только с вашего согласия.

Перед первым изменением рядом с `hosts` создаётся копия `hosts.valdoctor-original.bak`, перед
каждым следующим `hosts.valdoctor-previous.bak`. Перед запросом прав администратора ValDoctor
заново проверяет найденные адреса и сам файл. Если что-то изменилось, проверка запускается снова.

Отменять исправление лучше кнопкой «Отменить изменения». ValDoctor удалит только свои строки
и вернёт чужие записи, которые он закомментировал. Ваши собственные правки в `hosts` останутся.

Если программа не запускается, `hosts` можно поправить в Блокноте, открытом от имени
администратора:

1. Удалите блок от `# >>> ValDoctor BEGIN` до `# <<< ValDoctor END`.
2. Найдите строки, которые начинаются с `# valdoctor-off:` (у RiotFix `# riotfix-off:`). Это чужие
   записи, отключённые ValDoctor. Чтобы вернуть запись, удалите начало строки вместе с меткой
   и пробелом после неё. Если удалить только блок, эти записи останутся отключёнными.

Копия `hosts.valdoctor-original.bak` хранит файл в том виде, каким он был до первого изменения.
Если заменить ею `hosts`, пропадут все правки, сделанные позже, в том числе вами и другими
программами. Пользуйтесь ею, только если другие способы не помогли.

Записи, оставленные RiotFix версий 0.1.0, 0.2.0 и 0.2.1, программа распознаёт и отменяет так же.

## Ограничения

- ValDoctor проверяет сетевую доступность. Успешная проверка не гарантирует, что получится войти
  в аккаунт или в игру: авторизация, игровые серверы и Riot Vanguard не проверяются.
- Программа не поможет, если соединение блокируется по имени сайта (DPI), если Riot Client
  работает через прокси или VPN, а также при проблемах с аккаунтом или сбое у Riot Games.
- Если ни один найденный адрес не прошёл проверку, `hosts` не меняется.
- Найденный адрес со временем может перестать работать. Тогда запустите проверку ещё раз.
- Если `hosts` защищён антивирусом, доступен только для чтения или занят другой программой,
  ValDoctor сообщит об ошибке и ничего не изменит.

## Безопасность и конфиденциальность

- Программа не читает и не запрашивает логины, пароли, токены и cookie.
- Телеметрии и своего сервера нет. ValDoctor обращается только к проверяемым сервисам Riot,
  к публичным серверам DNS-over-HTTPS и не чаще раза в сутки к GitHub, чтобы узнать о новой версии.
  Обновления он не скачивает и не устанавливает сам.
- Окно программы работает с обычными правами. Права администратора нужны только короткому
  процессу, который записывает `hosts`. Он принимает только имена сервисов Riot из встроенного
  списка и публичные IP-адреса.
- С игрой, античитом и их файлами программа не взаимодействует.
- Журналы хранятся в `%LocalAppData%\ValDoctor\logs`.
- EXE собирается в GitHub Actions из этого репозитория после прохождения тестов.

Об уязвимостях сообщайте через
[Security Advisories](https://github.com/IskhakovMA/riotfix/security/advisories/new), а не в
открытых Issues.

## Сборка из исходников

Нужен [.NET SDK 10](https://dotnet.microsoft.com/download/dotnet/10.0).

```powershell
git clone https://github.com/IskhakovMA/riotfix.git
cd riotfix
dotnet test ValDoctor.slnx -c Release
dotnet publish src/ValDoctor.App/ValDoctor.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

Готовый файл: `publish\ValDoctor.exe`. Код диагностики и работы с `hosts` лежит в
`src/ValDoctor.Core`, интерфейс в `src/ValDoctor.App`, тесты в `tests/ValDoctor.Core.Tests`.
Тесты не трогают настоящий `hosts`.
